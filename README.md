# BonCloud

Plataforma educativa de comercio exterior enfocada en el Puerto de Cartagena: ruta de
aprendizaje con quizzes, calculadoras de importación y exportación, Incoterms 2020,
subpartidas, vistos buenos, formularios DIAN de práctica y simulador logístico.

| Carpeta | Qué es | Publicado en |
|---|---|---|
| [`web/`](web/README.md) | Frontend React + Vite | GitHub Pages |
| [`backend/`](backend/) | API Express + PostgreSQL (login, registro, progreso) | Render |

Contenido educativo: no reemplaza la asesoría de una agencia de aduanas ni la normativa
vigente de la DIAN.
